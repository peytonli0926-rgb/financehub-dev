# 零售融资租赁回租付款接口

接口：`POST /retail-leaseback/payment/execute`

来源系统固定为 `CYCXT`，业务编码固定为 `CYC_RETAIL_LEASEBACK`。接口的 `eventCode` 使用零售融资租赁业务系统的事件名称。`eg_field_mapping` 值映射将来源事件路由到 `CYC_PAYMENT` 付款场景，并映射出模板内部事件码，共用一张“零售回租统一付款模板”。

配置结构为：1 个接口、1 个付款场景、1 张凭证模板、15 个不重复资金类型分录头。不同事件和金额公式配置在分录条件中，因此新增付款事件不需要复制整张模板。

## 事件与金额校验

| 模板内部事件码 | 零售系统事件示例 | 金额要求 |
|---|---|---|
| CR003 | 购入租赁资产 | `paymentAmount > 0`；可选首付款 `initialPaymentAmount` |
| CR025 | 支付资产管理费 | `paymentAmount` 为含税实付总额；不含税管理费=`paymentAmount/(1+配置税率)`，税额=`paymentAmount-不含税管理费` |
| CR029 | 平台合作方分润 | `paymentAmount = refundAmount + offsetAmount + bankPaymentAmount` |
| CR036 | 支付银行手续费 | `paymentAmount > 0` |
| CR040 | 抵押服务费 | `paymentAmount = untaxedAmount + untaxedAmount × 配置税率` |
| CR041 | 支付通联手续费 | `paymentAmount = untaxedAmount + untaxedAmount × 配置税率` |
| CR044 | 渠道商分成结算 | `paymentAmount > 0` |
| CR056 | 合作方提前结清 | `paymentAmount = interestAmount + interestAmount × 配置税率` |

例如来源事件 `购入租赁资产` 映射为内部事件 `CR003`，`退回平台合作方提前结清贴息金额` 映射为内部事件 `CR029`；二者的目标场景均为 `CYC_PAYMENT`。接口不需要传 `sceneCode`。

CR003 的 `paymentMethod` 支持 `BANK_TRANSFER`、`BANK_ACCEPTANCE`；`assetStage` 支持 `COMPLETED`、`CONSTRUCTION`。其余事件默认为银行转账。

接口不接收 `taxRate` 和 `taxAmount`。引擎根据业务类型 `CYC_RETAIL_LEASEBACK` 读取 `tax_general` 通用有效税率。CR025从含税付款总额反算不含税资产管理费和进项税；CR056使用 `interestAmount` 作为计税基础；CR040、CR041使用 `untaxedAmount`。不同事件不再重复配置税率。

所有金额不得为负。币种不传时默认为 `CNY`。

## 我的单据

接口接收成功后先登记接口单据，再生成凭证并更新处理状态。“我的单据 > 接口单据”是所有来源系统共用的入口，只展示单据编号、来源系统、业务事件、客户、合同、业务日期、状态和操作等通用字段；制证成功后可从该行进入“查看凭证”。来源系统的专有字段保留在原始报文中，不作为公共列表列。

当前生命周期测试统一关联合同 `HXZL-PC-202609-0001`，由既有起租单据开始，后续购入租赁资产、各类手续费/服务费、渠道分成、提前结清相关付款均作为同一合同的后续单据展示。

## 银行账号与科目

所有 `bank_deposit` 分录均不在 `eg_account` 固定科目。引擎使用请求的 `bankAccountNo` 查询 `eg_bank_account.bank_account_number`，将该记录的 `account_code`、`account_name`写入凭证分录。

测试账号：

| 银行账号 | 银行 | 动态科目 |
|---|---|---|
| 1000000000000000001 | 工商银行 | 1002.01 银行存款-工商银行 |
| 1000000000000000002 | 招商银行 | 1002.12 银行存款-招商银行 |
| 1000000000000000003 | 兴业银行 | 1004.01 存放同业-兴业银行 |
| 1000000000000000004 | 浦发银行 | 1004.06 存放同业-浦发银行 |

这些记录带有 `KD-CYC-BA-*` 金蝶主键 `eas_id`，用于模拟金蝶同步已完成。

## 返回

成功时沿用会计引擎统一返回结构，`data` 为生成的凭证列表。校验失败时返回明确原因，包括不支持的事件、金额不平、银行账号未同步、银行账号未关联会计科目等。
