# 零售回租辅助账调整及其他场景接口说明

适用业务：融资租赁业务 / 回租 / 乘用车，来源系统为零售融资租赁业务系统。

接口：

- `POST /retail-leaseback/auxiliary-account-adjustment/execute`
- `POST /retail-leaseback/other/execute`

辅助账调整包括“项目承租人发生变更”“因辅助核算项目挂错，调整相关科目”2 个业务事件。其他包括“内部资金调拨、头寸调拨、季度结息、多支付分润费挂账、金额记错调整、调整违约金分成、促销核准补差合作方分润费”7 个业务事件。

季度结息根据来源事件字段区分存放同业和银行存款两套科目规则，但在单据界面统一显示“季度结息”。内部资金调拨和头寸调拨共用唯一的 `transferAmount` 金额字段；其他金额类型也不重复配置。

