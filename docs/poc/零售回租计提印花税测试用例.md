# 零售回租计提税金—印花税测试用例

## 场景定义

- 触发源：零售融资租赁业务系统的乘用车回租起租事件。
- 触发方式：起租凭证成功后由会计引擎内部自动触发；不提供外部印花税接口。
- 审批方式：无需审批，内部事件记录 `approvalRequired=false`、`approvalStatus=NOT_REQUIRED`。
- 幂等键：`起租单号 + -AUTO-JTYS`，重复处理起租事件不会重复计提。
- 税率来源：业务类型 `CYC_RETAIL_LEASEBACK` 下的 `stamp_duty` 税率配置，事件报文不传税率。
- 计算公式：起租还款计划租金总额（不含留购价）× 0.005%，四舍五入保留两位小数。

## 已执行用例

| 项目 | 实际结果 |
|---|---|
| 关联合同 | `HXZL-PC-202609-0001` |
| 触发起租单据 | `HTQZ-20260903-0001` |
| 自动事件单据 | `HTQZ-20260903-0001-AUTO-JTYS` |
| 计税基础 | 123,935.66元（合同金额124,935.66元扣除留购价1,000元） |
| 配置税率 | 0.005% |
| 印花税金额 | 6.20元 |
| 接口单据状态 | `SUCCESS` |
| 凭证状态 | 已生成，`validFlag=1` |
| 审批记录 | 0条 |
| 借方分录 | 640305 税金及附加—印花税，6.20元 |
| 贷方分录 | 222108 应交税费—应交印花税，6.20元 |
| 合同余额 | 印花税费用6.20元；应交印花税6.20元 |

## 验收入口

1. “我的单据”按合同 `HXZL-PC-202609-0001` 查询，可看到自动接口事件并查看报文、凭证。
2. “单合同查询”进入该合同，在“交易流水”中可看到“计提税金—印花税”。
3. 在“科目余额”中可看到印花税费用、应交印花税的发生额和余额。
