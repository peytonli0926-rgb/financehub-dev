# 零售回租计提资产管理费测试用例

## 场景说明

- 业务系统：零售融资租赁业务系统
- 业务：乘用车回租
- 合同：`HXZL-PC-202609-0001`
- 场景编码：`CYC_ASSET_MANAGEMENT_FEE_ACCRUAL`
- 事件编码：`JTZCGLF`
- 触发方式：月末定期自动执行，无需审批
- 计提口径：接口仅传不含税资产管理费金额，不传税率和税额；税率由业务类型配置，在付款或发票环节处理税额
- 月度约束：同一合同、同一会计月份只允许成功计提一次

## 接口定义

`POST /retail-leaseback/management-fee-accrual/execute`

请求示例：

```json
{
  "orderId": "HXZL-PC-202609-0001-MFA-202609",
  "eventCode": "JTZCGLF",
  "businessDate": "2026-09-30 23:50:00",
  "contractCode": "HXZL-PC-202609-0001",
  "managementFeeAmount": 1000.00,
  "currency": "CNY",
  "remark": "2026年9月资产管理费月末计提"
}
```

`contractCode` 是必填接口字段。合同主键、合同名称、客户和签约主体由系统根据合同主数据补齐，不由定期任务重复传入。

## 凭证模板

| 方向 | 科目编码 | 科目名称 | 金额表达式 |
|---|---|---|---|
| 借 | 64210409 | 手续费及佣金支出-项目手续费-车辆资产管理费 | managementFeeAmount |
| 贷 | 220211 | 应付账款-应付车辆管理费 | managementFeeAmount |

费用分录配置“客户档案＋合同号”辅助核算，凭证行必须写入客户 `CUST-PC-000001`、合同 `HXZL-PC-202609-0001`；两条分录均进入该合同的科目余额。

凭证日期为业务日期 `2026-09-30`，会计期间为 `202609`。

## 测试用例

### MFA-01 月末正常计提

- 前置条件：合同已于 `2026-09-03` 起租。
- 输入：使用上述请求，计提不含税管理费 `1000.00` 元。
- 预期：接口单据状态成功；不产生审批任务；生成一张两行凭证；借贷各 `1000.00` 元；凭证日期和会计期间正确。
- 查询验证：在“我的单据”中可按合同查询到该接口单据；在“单合同查询”的交易流水中可看到“计提资产管理费”，并可查看对应凭证和科目余额。

### MFA-02 同月重复计提拦截

- 前置条件：MFA-01 已成功。
- 输入：将流水号改为 `HXZL-PC-202609-0001-MFA-202609-DUP`，其余数据保持在 `2026-09`。
- 预期：系统提示该合同当月已经计提，不生成接口单据、审批任务、凭证或余额变动。

### MFA-03 非正金额校验

- 输入：流水号为 `HXZL-PC-202609-0001-MFA-ZERO`，`managementFeeAmount` 为 `0`。
- 预期：请求校验不通过，不生成接口单据、审批任务、凭证或余额变动。

## 生命周期时间顺序

`2026-09-03 起租` → `2026-09-04 资产管理费付款` → `2026-09-30 月末计提资产管理费` → `2026-09-30 收益计提`

现有付款事件用于实际结算，月末计提事件用于确认当期费用及应付款；两者通过应付车辆管理费科目形成勾稽关系。
