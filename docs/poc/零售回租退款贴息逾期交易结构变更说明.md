# 零售回租补充场景接口及测试说明

本次将退款、贴息确认、逾期、交易结构变更配置为四个独立财务中台场景。业务系统传事件名称或编码，值映射转换为中台事件后选择凭证模板。同一场景内每种金额类型只配置一个字段。

接口：

- `POST /retail-leaseback/refund/execute`
- `POST /retail-leaseback/subsidy-confirm/execute`
- `POST /retail-leaseback/overdue/execute`
- `POST /retail-leaseback/transaction-structure-change/execute`

事件范围：退款 3 类、贴息确认 3 类、逾期 4 类、交易结构变更 12 类。交易结构变更金额使用有符号差额，正数调增、负数调减，模板自动切换借贷方向。

自动测试覆盖全部 22 个正向事件和 4 个负向校验：

```powershell
& '.\执行零售回租补充场景测试.ps1'
```

配置脚本为 `code/financehub-engine/sql/20260909_retail_leaseback_additional_events.sql`。
