# 零售回租统一收款接口及测试说明

接口：`POST /retail-leaseback/collection/execute`

业务系统传入事件名称或事件编码，值映射统一进入财务中台 `CYC_COLLECTION`（收款）场景：

| 内部事件 | 来源业务事件 | 凭证处理 |
|---|---|---|
| CR000 | 收到现金折扣 | 借银行存款，贷租赁资产成本 |
| CR001 | 收取/收到保证金 | 借银行存款，贷客户保证金 |
| CR005 | 到并核销租金 | 借银行存款，贷本金、利息、税额、留购价及税额 |
| CR006 | 款项无法确认 | 借银行存款，贷其他预收款 |
| CR007 | 人工明确款项用途 | 借其他预收款，贷已确认用途对应科目 |
| CR008 | 收到款项核销 | 借其他预收款，贷本次核销对应科目 |
| CR033 | 退回的分润费 | 借银行存款，贷应收分润款 |
| CR043 | 前期逾期留购价 | 借银行存款，贷逾期留购价及税额 |

场景内每个金额含义仅有一个字段，例如 `principalAmount`、`depositAmount`。银行到账类事件共用收款模板，CR007/CR008 共用转账核销模板，并通过字段金额大于零决定实际生成的分录。

测试文件包含 8 个正例和 4 个反例。成功用例流水号前缀为 `HXZL-PC-202609-0001-COL2-`，均会保留在“我的单据”和“凭证查询”中。
