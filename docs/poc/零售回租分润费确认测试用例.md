# 零售回租分润费确认测试用例

## 接口定义

- 地址：`POST /retail-leaseback/profit-sharing/execute`
- 一个接口统一接收 `FRF_CONFIRM`（起租日确认）和 `FRF_REFUND`（退回）两个事件。
- 必填字段：`orderId`、`eventCode`、`businessDate`、`contractCode`、`profitSharingAmount`。
- 可选字段：`triggerOrderId`、`currency`、`remark`。
- 合同、客户和签约主体从合同主数据取得，接口不重复传递；同一`orderId`重复提交会被拒绝。
- 两个事件共用“零售回租分润费确认模板”，均自动生成凭证且无需审批。

## 用例一：起租日确认分润费

接口请求：

```json
{
  "orderId": "HXZL-PC-202609-0001-FRF-01",
  "eventCode": "起租日确认分润费",
  "businessDate": "2026-09-03 10:05:00",
  "contractCode": "HXZL-PC-202609-0001",
  "profitSharingAmount": 3000.00,
  "triggerOrderId": "HTQZ-20260903-0001",
  "currency": "CNY",
  "remark": "起租日确认平台分润费"
}
```

预期凭证：

| 借贷 | 科目 | 金额 |
|---|---|---:|
| 借 | 112503 应收账款-车辆清分款 | 3,000.00 |
| 贷 | 220212 应付账款-应付车辆分润费 | 3,000.00 |

## 用例二：退回分润费

接口请求：

```json
{
  "orderId": "HXZL-PC-202609-0001-FRF-02",
  "eventCode": "退回分润费",
  "businessDate": "2027-06-20 09:30:00",
  "contractCode": "HXZL-PC-202609-0001",
  "profitSharingAmount": 500.00,
  "triggerOrderId": "HTQZ-20260903-0001",
  "currency": "CNY",
  "remark": "提前结清前退回部分分润费"
}
```

预期凭证：

| 借贷 | 科目 | 金额 |
|---|---|---:|
| 借 | 220212 应付账款-应付车辆分润费 | 500.00 |
| 贷 | 112503 应收账款-车辆清分款 | 500.00 |

仅看这两个事件的净影响：应收车辆清分款增加2,500.00元，应付车辆分润费增加2,500.00元。单合同查询展示的期末绝对余额还会叠加该合同此前已经执行的付款、抵扣等生命周期事件。两张凭证均自动生成且无需审批。
